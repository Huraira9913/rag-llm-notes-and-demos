# RAG & LLM Notes and Demos

Practical notes and working demos for **Retrieval-Augmented Generation (RAG)** and basic LLM applications.

## Contents

- Simple RAG pipeline with FAISS + sentence-transformers
- Document chunking strategies
- Embedding models
- Question-answering over your own documents
- FastAPI endpoint example patterns
- Prompt engineering patterns

## Quick Start

```bash
pip install -r requirements.txt
python demos/simple_rag.py
```

## Skills Developed

- Building retrieval pipelines
- Evaluating retrieval quality (basic)
- Integrating LLMs safely (prompt design, grounding)
- Serving LLM apps via FastAPI
